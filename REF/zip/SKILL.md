# Mythogen Engine 文章自動標籤系統

將未標記的 Markdown 文章自動歸類到 Mythogen Engine 網站結構，生成完整的 YAML front matter。標籤系統雙語：中文書面語（港台統一）+ English。同時自動偵測文章語言並標記。

## 運作流程

1. **讀取文章** — 讀入 Markdown 內容，判斷是否已有 YAML front matter
2. **偵測語言** — 判斷文章主體語言（zh-Hant / zh-HK / en / mixed）
3. **分析內容** — 識別文章主題、論點、涉及的產業/人物/概念
4. **歸類板塊** — 對應到網站的五大板塊之一
5. **生成標籤** — 從標籤庫中選取匹配的標籤（參見 `references/tag-library.md`）
6. **輸出 YAML** — 在文章頂部插入完整的 front matter
新文章的檔名不要加日期前綴，日期只放在 frontmatter 裡。其餘照常操作就好。

## 網站板塊定義

文章必須歸入以下五個板塊之一：

| 板塊 ID | 中文名稱 | English | 內容範圍 |
|---------|---------|---------|---------|
| `ai-archive` | AI 產業深度分析 | AI Ecosystem War | 八章產業分析書：微軟與蘋果的 AI 生態暗戰、OpenAI 資金結構、Claude Code vs Copilot、贏家與輸家 |
| `mirror-realm` | 鏡界殺人史 | Mirror Realm | 長篇連載科幻小說，融合故障大體引擎渲染的世界、半自傳經歷、虛構世界觀與日記碎片 |
| `gamevictory` | 科技歷史 | GameVictory | 遊戲產業如何鋪設 AI 革命底層軌道：GPU 算力競賽、平台生態戰爭、四十年科技霸權的隱藏算術 |
| `sober-record` | 清醒記錄 | Sober Record | 獨立 AI 產業評論與社會觀察：賣課經濟的焦慮套利、AI 就業市場結構性收縮、科技巨頭敘事操作 |
| `freewrite` | 隨心書寫 | Diary / Freewrite | 沒有框架、沒有計劃，只是寫。關於職場、關於系統、關於一個人怎麼在體制裡找到自己的語言 |

### 歸類判斷邏輯

按以下順序判斷，命中即停：

1. 若文章是科幻小說章節、角色設定、世界觀片段 → `mirror-realm`
2. 若文章主題是遊戲產業歷史、GPU/主機硬體演進 → `gamevictory`
3. 若文章屬於八章產業分析書的某一章 → `ai-archive`
4. 若文章是 AI 產業評論、就業分析、教育批判、媒體素養 → `sober-record`
5. 若以上皆非（個人隨筆、日記、情感抒發） → `freewrite`

## YAML Front Matter 模板

```yaml
---
title: "[由內容生成的標題]"
date: YYYY-MM-DD
lang: [文章語言代碼]
section: [板塊 ID]
topic: [主題標籤 ID]
tags:
  zh:
    - [中文書面語標籤]
  en:
    - [english-tag]
keywords:
  - [3-5 個從文章內容擷取的關鍵詞]
summary: "[一句話摘要，50字以內]"
status: [draft | review | published]
reading_time: [估算閱讀分鐘數]
---
```

## 語言偵測與 `lang` 欄位

`lang` 標記文章本身的書寫語言，用於網站的多語言路由和 SEO。

### 合法值

| lang 值 | 含義 | 判斷依據 |
|---------|------|---------|
| `zh-Hant` | 台灣正體中文 | 使用台灣用詞習慣（軟體、程式、網路、資料） |
| `zh-HK` | 香港書面中文 | 使用香港用詞習慣（軟件、程序、網絡、數據） |
| `en` | English | 全文或主體為英文 |
| `mixed` | 混合語言 | 中英夾雜且無法判定主體語言，或刻意雙語並行 |

### 判斷邏輯

依以下順序判定：

1. 全文英文 → `en`
2. 全文中文，檢查關鍵用詞：
   - 出現「軟體」「程式」「網路」「資料」等台灣用詞 → `zh-Hant`
   - 出現「軟件」「程序」「網絡」「數據」等香港用詞 → `zh-HK`
   - 兩者皆有或無法判定 → 預設 `zh-Hant`（因網站台灣版為主版本）
3. 中英夾雜但主體可辨 → 依主體語言判定
4. 無法判定主體 → `mixed`

## 標籤規則

### 中文標籤（`zh`）

港台書面語標籤統一為一套。用詞以港台共通的書面語為準——大部分標籤港台一致（如「平台壟斷」「焦慮套利」「生態系戰爭」），少數有差異的以較通用的表述為準，或採用不涉及港台差異的寫法。

例如：用「AI」而非「人工智慧」或「人工智能」，用「開源」（兩地一致），避免在標籤層面出現需要區分的詞彙。

完整標籤列表見 `references/tag-library.md`。

### English 標籤（`en`）

英文標籤為中文標籤的對應翻譯，使用業界通用術語。不是逐字翻譯，而是對應英文世界慣用的概念名稱。

格式：全小寫，單詞間用連字號 `-` 連接。

### 標籤數量

- `tags.zh`: 2-5 個
- `tags.en`: 與 zh 數量一致，一一對應
- `keywords`: 3-5 個，從文章擷取的具體名詞或概念
- `topic`: 恰好 1 個

## 處理流程細節

### 單篇文章

讀取 → 偵測語言 → 分析 → 生成 YAML → 插入文章頂部 → 輸出到 `/mnt/user-data/outputs/`

### 批量處理

讀取資料夾中所有 `.md` 檔案 → 逐一分析 → 生成各自的 YAML → 分別輸出。批量時先輸出一份摘要表格：

```
| 檔名 | lang | 板塊 | 主題 | 標籤數 |
|------|------|------|------|--------|
| ... | ... | ... | ... | ... |
```

讓使用者確認歸類是否正確，再執行寫入。

### 已有 YAML 的文章

若文章已有 front matter，執行**合併而非覆蓋**：保留原有欄位，補充缺失的欄位。標記衝突讓使用者決定。

## 品質檢查

生成 YAML 後自動檢查：

- `lang` 是否為四個合法值之一
- `section` 是否為五個有效值之一
- `topic` 是否為 `references/tag-library.md` 中的合法 topic ID
- `tags.zh` 和 `tags.en` 數量是否一致且一一對應
- `tags` 是否從 `references/tag-library.md` 的合法標籤中選取
- `date` 格式是否為 ISO 8601
- `summary` 是否在 50 字以內
- `reading_time` 是否合理（中文每分鐘 500 字，英文每分鐘 250 詞）
