# 後記　關於你正在做的事

你讀到這裡，本身就是一種選擇。

這本書不會被演算法推薦給你。它沒有恆真句來觸發你的情緒，沒有「三分鐘學會」的標題來吸引你的點擊，沒有焦慮來驅動你的分享。它要求你花好幾個小時閱讀，要求你跟著論證從第一章走到終章，要求你在讀完之後自己判斷——而不是被判斷。

演算法獎勵的是情緒反應的強度和速度，不是思考的深度。所以像這樣的內容，在平台的自然分發裡幾乎沒有機會被看見。第五章拆過這個結構：當內容的可見度與它的商業價值直接掛鉤，深度分析就永遠排在情緒點擊的後面。

但你看見了。

不是因為演算法覺得你需要看。是你自己走到了這裡。也許有人傳給你，也許你在某個角落偶然碰到，也許你讀完序章那段叔本華之後決定繼續往下翻。不管怎樣，你用了自己的判斷力來決定要不要花這些時間。這件事本身，就是這本書試圖捍衛的東西——獨立判斷的能力。

如果你覺得這本書說了一些值得被更多人看見的東西，那麼你能做的最具體的事，就是把它傳給一個你覺得會明白的人。

不是為了幫我。

是因為書的傳播單位從來不是讚好，是人。每一次轉交，都是在告訴這個由演算法分發一切的環境：有些東西，人會自己揀。

第一章拆過資訊在傳播中的變形。但有一種傳播方式不太會變形——一個人把一本書交到另一個人手裡，然後說：「你看看這個。」這個動作沒有標題壓縮、沒有翻譯走樣、沒有編輯取角。它只有一層：我覺得這值得你花時間，你自己判斷。

反演算法邏輯的內容，需要反演算法邏輯的傳播方式——靠人，不靠機器。
