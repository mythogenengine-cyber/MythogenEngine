# 終篇：數得清楚之後

**解決問題，從來不只一步**

@Mythogen Engine · 2026年10月24日

## 牆上的簿

塔裡終於有人把那本簿公開了。每一層吃了多少，頂層拿了多少，逐層列出來，貼在每一層的牆上。

第二天，平台照樣從頂層降下來。頂層照樣先吃。

下層的人看著牆上的數字，終於知道自己少了多少。他們開始對著上一層喊，這次喊的是數字。上一層也看了牆，回道：我們也只是比你們多一點，去問上面。再上一層說：我們的飯是自己買下這個位置換來的，不要動。

簿上的數字一個不差，平台上的食物一粒不少。變的只是，大家終於可以拿著證據吵架。

「從乞丐碗裡搶飯」四篇，一直在要求一件事：把數字公開。這一篇要問的是：數得清楚之後，又怎樣？

## 一、台灣已經數得清楚

前四篇一直拿台灣作對照。香港說做不到的事，台灣大多做了：非自願離職有就業保險接住，移工人數按國籍逐月公布，外籍和大陸配偶從 1987 年起有連續統計。以「數得清楚」而言，台灣遠比香港做得好。

但台灣的打工仔並沒有因此過得好。

- **工資原地踏步**：2018 年 12 月，扣除物價後的實質經常性薪資是 38,235 元，比 2001 年還低（[TVBS](https://news.tvbs.com.tw/life/1085883)）。
- **勞工分到的份額創新低**：受僱人員報酬佔 GDP 比率，由 1990 年代初超過 50%，跌至 2024 年的 43.1%；同年企業營業盈餘佔比升至 35.06%（[經濟日報](https://money.udn.com/money/story/124921/9656403)）。
- **房子愈來愈遠**：台北市的房價所得比，由 2002 年約 6 倍升至 2025 年第一季的 15.57 倍（[經濟日報](https://money.udn.com/money/story/5621/8984160)）。

數字公開了，錢照樣往上流。移工按國籍逐月公布，家庭看護工卻仍然不適用《勞動基準法》，薪資長期低於基本工資。數得清楚，只是讓人看見；看見之後做不做，是另一件事。

## 二、是另一個維度，還是同一個方向？

香港和台灣的問題，機制幾乎完全不同，方向却一樣：勞動那一份縮細，資產那一份水漲船高。

|   |   |   |
|---|---|---|
|環節|香港|台灣|
|住屋保障|公屋和資助房屋曾覆蓋近半人口，近二十年門口愈收愈窄|社宅不到住宅存量 1.5%，靠八成四的自有率|
|工資被壓的主因|輸入外勞、收緊綜援|新台幣長期偏弱、資本密集產業、移工|
|政府依賴甚麼|賣地和土地相關收入|出口和半導體|
|人口入口|單程證由內地審批，住滿七年就數不到|自己審批，按國籍逐月公布|
|誰得益|地主、早上車的業主|出口企業的擁有人、股東、有房的家庭|

所以台灣不是另一個維度，而是下一個關口。香港的問題是：保障被拆掉，而且數不到。台灣的問題是：數得到，但整套制度本來就偏向持有資產的人。就算香港明天把數字全部公開、把公屋重新建起來，它遇到的，就是台灣今天的問題。

## 三、中產既是受害者，也是受益者

這是前四篇沒有正面說的一點，也是最不好聽的一點：往下踩的聲音，不全是被誤導，也有一部分是在保護自己的碗。

台灣的家庭住宅自有率是 83.95%（[經濟日報引主計總處](https://money.udn.com/money/amp/story/5621/9707866)）；香港也有一大批「上岸」的業主。對已經有房的人來說，樓價上升是財富，撤辣是好消息，持有稅低是應該的。他們一方面是打工仔，工資追不上生產力；另一方面是小業主，坐在平台的中段，吃的是下面的人交的租。

同一個人，下班時抱怨工資，到了業主立案法團開會，卻反對附近起公屋。他不是虛偽，只是他的碗同時放在兩層：勞動那一碗在縮細，資產那一碗在變大。他理性地保護正在變大的那一碗——代價是自己的子女、後來的人，上車的門檻愈來愈高。

這就是「政策一直在維持不均」的原因。不只是頂層要它維持，而是很多選民、很多議員，甚至很多讀這系列的人自己，都是受益者。平台上不只有頂層在多拿，每一層都有人把碗抱得更緊，防著下一層。

## 四、為甚麼解決不簡單

前四篇指出，最大的一筆帳是地租。但任何人想動地租，都會發現它和其他東西鎖在一起：拉一個環節，整條鎖就跟著動，最後又彈回原位。

:::note[圖表]

壓低地價的連鎖反應・六個環節

:::
這不是假設。香港樓價自 2021 年高位累計回落近三成，2024 年第三季負資產個案升至四萬多宗，創 21 年新高（[RFA](https://www.rfa.org/cantonese/news/htm/hong-kong-mortgage-negative-equity-real-estate-economy-10312024094418.html)）。地價下跌、樓市淡靜，土地收入大幅減少，2024/25 年度赤字估計約一千億港元（[公視](https://news.pts.org.tw/article/739229)）。然後被削減的，是第一篇留言區裡那些：長者乘車優惠、學生津貼。樓價跌了三成，底層並沒有因此分到更多；痛先落在高位上車的中產，再落在靠政府開支的人身上。

反過來向資本加稅，又會碰上第二篇說的那扇門：連全球最低企業稅的 15%，都要為美國跨國企業開豁免。一個地方單獨收緊，資本就走；庫房的缺口，最後又回到地價上。所以問題不是找不到一個正確的政策，而是任何一個政策單獨上場，都會被整條鎖拉回去。

## 五、還能做甚麼

沒有一個政策可以解開整條鎖。能做的，是同時拉幾個環節，而且拉得慢。

1. **先數清楚**。它不夠，但沒有它，其他一切都只是體感對體感。台灣證明了數得清楚不等於解決，但香港連這一步都未走。
2. **守住地板**。任何人跌下來，都食得飽、瞓得暖。地板穩了，底層就不必血鬥，壓力也不會逐層往上傳。這是第一篇的結論，也是整條鎖裡最便宜的一環。
3. **慢慢拉，不要一下拔**。地價一下崩下來，痛先落在高位上車的人身上；用幾十年穩定地增加公屋和居屋，讓私樓的天花板慢慢回來，就不必犧牲一整代業主。稅也一樣：台灣 2016 年起實施房地合一稅，2021 年再修訂，針對的是短期轉手的賺幅，而不是自住的家庭。方向對了，力度可以慢慢加。
4. **不再往下踩**。這一項不必等政府。競爭是各憑本事，鬥爭是一層踩一層；中小企老闆和打工仔、本地人和新來的人、業主和租客，坐的是同一個平台。看清楚這一點，聲音才有可能傳到頂層。

## 結語：簿只是開始

回到那座塔。簿貼在牆上之後，每一層的人都看得見：上面拿了多少，自己拿了多少，下面剩下多少。最難的一步不是把簿貼出來，而是每一層的人看完之後，有沒有人願意鬆開抱著碗的那隻手。

數得清楚之後，我們才會發現，要動的有一部分在自己手上。這不是厭富，也不是仇貧；是承認自己也在鎖上，然後仍然要求那條鎖被看見、被量度、被慢慢解開。
