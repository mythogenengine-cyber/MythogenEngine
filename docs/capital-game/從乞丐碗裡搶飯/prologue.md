# 序篇：從乞丐碗裡搶飯

**四篇文章，同一塊愈切愈細的餅**

@Mythogen Engine · 2026年10月24日

## 一座塔

一座看不見底的塔，每層兩個人。每天，一個堆滿食物的平台從頂層降下來，每層停一會兒，再往下一層。

上層的人先吃，吃不完也要多拿幾件。平台每降一層，桌上就少一點；到了下面，只剩骨頭和空碟。

下層的人仰起頭，只看得見上一層的地板。他們對著上一層喊：給我們留一點！上一層回罵：你們又沒有做事，憑甚麼吃？再下一層也在喊，喊的是對方多拿了一口。沒有人看得見頂層，也沒有人的聲音傳得到那裡。

有人拿著簿走過來，逐一點算下層每一碟剩下的骨頭，記得清清楚楚。頂層吃了多少，簿上沒有這一格。

下層吵得愈大聲，頂層吃得愈安靜。

看過 2019 年西班牙電影《絕命大平台》的讀者，會認得這個畫面。但現實與電影有兩個分別。第一，電影裡的食物本來就夠所有人吃；現實裡，平台上的食物還在增加，生產力幾十年來一直上升。少了的不是食物，是分到下面的份額。第二，電影裡有一個設計平台的「管理處」；現實沒有。金融化的資本是一套自動運轉的系統，回報要求一層壓一層，連坐在頂層的人也停不下來。它不需要誰是壞人，也就沒有一個人可以叫它停。

## 中心思想

這個系列只說一件事：錢一直流向頂層，留在下面的那一份年年縮細；其餘所有人，却被引導去跟身邊的人爭。

全球最富 1% 的人擁有約 37% 的財富；美國勞工分到的產出份額，跌到 1947 年有紀錄以來最低；台灣的受僱人員報酬佔 GDP 比率，創歷史新低。這些數字很少成為話題。成為話題的，是綜援戶為甚麼不打工、新來的人有沒有住公屋、非洲的孩子比你慘多少。

傳媒、社會和大眾，很自然地只跟身邊的上下兩層比。比來比去，都是在同一塊愈切愈細的餅上爭奪。這不是競爭。競爭是各憑本事，把餅做大；鬥爭是一層踩一層，你多拿一口，就是旁邊的人少一口。鬥爭最後會波及每一層：基層爭工，文員的工資被壓；文員爭位，白領的工時拉長。連大眾眼中的「有錢人」——中小企老闆、傳統行業的廠家和店主——也困在同一塊餅上。

古人說「不患寡而患不均」。今天的問題正是不均，而不少政策一直在維持它：收緊的總是量得到的底層，地租和資產則原封不動。

所以這個系列不是厭富，也不是仇貧，更不是要可憐誰。總有人說「這個世界沒有甚麼是應得的」，但這句話只會向下說，從來不會說給業主和股東聽。看清結構，就是拒絕這條只准往下用的道理，拿回應得的那一份。

## 四篇文章

**之一〈不做就該受苦？從綜援到 UBI，「多勞多得」是誰的原則〉**。從屯門富泰邨一宗女童搬啤酒的片段說起：兩分鐘之內，一宗疑似虐兒案變成了一宗福利案。文章追問「不工作的人就應該過得更慘」這個前提，它來自 1834 年英國的濟貧法，功能從來是壓低工資。被指著的是綜援戶；沒有人問的是，生產力上升了幾十年，成果去了哪裡。結論：社會需要有人工作，不等於人要工作才配活；安全網的高度，決定的是每一層的地板。

**之二〈全球的上層，本地的下層〉**。一位月薪兩萬二的行政主任，在全球排名表上排前四分之一，交完租卻買不起一部手機。有人叫她想想非洲的孩子，有人叫她害怕湧來的窮人；沒有人問錢去了哪裡。文章拆解罪疚與恐懼兩個陷阱，以及資本為甚麼走得、人走不得。結論：大家在同一塊愈切愈細的餅上爭奪，而切走大半塊餅的人，從來不在比較之內。

**之三〈看得見的騙，量不到的數〉**。公屋在香港行之有效幾十年，今天卻像無故全面失效：中位數打工仔不合資格，合資格的要等五年多。審查量得到糧單，量不到現金和境外資產；被剔走的，是老實報糧的人。被指著的是公屋戶和申請人；沒有人量的是，地租落在誰手上。結論：騙福利是執法問題，不是保障本身的問題。

**之四〈走的和來的〉**。統計處只公布淨數：本地人走了多少、人才來了多少，互相抵銷。單程證、雙非、各項人才計劃，住滿七年就一律計作「本地」，來路從此消失。被指著的是新來的人；沒有人數的是，誰搬進了誰的單位，租金又流向誰。結論：要數據不是歧視；不是量不到，而是不去量。

**終篇〈數得清楚之後〉**。台灣已經數得清楚，工資卻一樣原地踏步、房子一樣買不起。終篇問的是：數字公開之後又怎樣？答案並不輕鬆——中產既是受害者也是受益者，而地價和財政、稅基、資本鎖在一起，任何一個政策單獨上場，都會被整條鎖拉回去。

## 四篇怎樣連在一起

四篇文章各有題目，結構却是同一個：每一篇都有一群人被指著，也都有一筆帳沒有人計。

|   |   |   |   |
|---|---|---|---|
|篇|被指著的人|用來指著他們的說法|沒有人問的帳|
|之一|綜援戶|「不做就該受苦」|生產力的成果去了哪裡|
|之二|非洲的孩子、湧來的窮人|「你在全球已經很富」|最富 1% 擁有約 37% 的財富|
|之三|公屋戶、申請人|「騙福利的人很多」|地租落在誰手上|
|之四|新來的人|「不要分化、不要歧視」|誰走了、誰來了、租金流向誰|

第一、二篇講的是說法：甚麼話術把目光引向底層。第三、四篇講的是數字：制度量度甚麼、不量度甚麼。兩者互為表裡——只量底層的數字，為「往下踩」的說法提供彈藥；「不要歧視」一類的說法，又反過來阻止人要求數字。

第二、三篇共用同一個人物，四篇共用同一個對照。第二篇的行政主任阿欣，在第三篇走到房署的櫃位前，發現自己連隊都排不進。每一篇都拿台灣作對照：台灣有就業保險、有按國籍逐月公布的移工數字，也有自己的房價和工資問題。對照不是要說台灣比較好。台灣做到了香港說做不到的事，工資卻一樣原地踏步，台北的房子一樣要十五年多收入才買得起。這說明兩件事：香港「做不到」的藉口站不住腳；但單靠保險和數字，也擋不住錢往頂層流。

## 怎樣讀

四篇可以單獨讀，但按次序讀最清楚：第一篇拆前提，第二篇放大到全球，第三篇回到香港的公屋和綜援，第四篇追到人口的入口和統計本身。

文章裡的數字都附上來源；查不到的，就寫明查不到，不用體感代替數字。這一點本身就是系列的論點之一：很多最關鍵的數字，不是不存在，而是沒有人公開。
