# 錯誤曾經是攤開的

@Mythogen Engine · Nov 12, 2026

## 那個不用花錢的年代

十幾年前，網路學院剛剛興起，Stack Overflow 正當紅。那是無數工程師自學的黃金年代。當時甚至有一種共識：學寫程式根本不需要花錢，而且不花錢反而學得更深、更扎實，因為你被迫自己去碰底層。

Java、JavaScript、Python，我都是那樣自學的。我說不出自學到底能去到甚麼程度，但當年至少夠用。這些年很少再親手寫，今天叫我空手做 LeetCode，語法大概要重新查，一些邏輯規則也未必記得。

但現在用 AI 半自動寫程式，我寫起來反而沒有問題。語法交給 AI，我負責判斷：它給的東西對不對，錯在哪裡，應該往哪個方向改。語法會生鏽，這種判斷不會；而正正是這種判斷，決定了 AI 對你來說是加速器，還是神諭。

當然，這有範圍。自己做的工具、網站、腳本，這樣做綽綽有餘；大型協作是另一回事，那涉及團隊規範、程式庫的歷史、審查流程，不是個人判斷力或 AI 可以補上的。這篇文要談的是前一種：一個人怎樣練出不會生鏽的判斷。

今天有了 AI，方便得多。但老實說，總覺得少了當年泡在 Stack Overflow 裡那種踏實感。這篇文想把那種踏實感拆開來看：它到底是甚麼，誰把它拿走了，以及為甚麼拿不回來。

## 一個最佳解答背後，站著甚麼

Stack Overflow 真正的價值，從來不是答案本身，而是答案旁邊那一層公開驗證。

一個被選為最佳的解答，底下有票數，代表有多少人試過、認為可行。再往下是留言：有人指出某一行在新版本會出錯，有人補充另一種寫法，有人直接反駁。答案上面有日期，有編輯紀錄，有人註明「此方法只適用於 Python 2」。你不只看到一個答案，你看到一場已經吵完的架，連同各方的論點一併攤開。

更重要的是，這個社群會逼你進步。你問得含糊，第一個留言多半是「你用的是哪個版本？」；不補資料，就被投反對票、被關帖。那很痛，但痛過幾次，你就學會把版本、環境、錯誤訊息一次寫清楚。

所以 Stack Overflow 上一直存在兩種人：發問會寫版本的，和一句「為甚麼不能用」就問的；回答會註明適用範圍的，和貼一段程式碼就走的。有經驗的人搜尋時本身就會加上版本，答案也寫明版本，過時的解答自然不會排在前面。真正中伏的，是還不知道要加版本的新手。

但這條界線是看得見的，而且有路可以走過去。社群用一次又一次的追問，把人從含糊推向精準。

## AI 拿走的不是答案，是驗證層

AI 的隱形成本，關鍵在「答案的公信力」。

Stack Overflow 的公信力是看得見、分散的：票數、留言、日期、版本、反對意見，全部公開。AI 的公信力是看不見、集中的：一把很有自信的聲音，給你一個答案，底下沒有人說它錯。

驗證的成本沒有消失，只是由社群轉嫁回用家身上。而剛入門的人，偏偏最沒有能力承擔這個成本。

舉一個具體例子。Tailwind CSS 由 v3 到 v4，設定方式大改：v4 改為直接在 CSS 裡設定，不再預設使用 tailwind.config.js。你問 AI「Tailwind 怎樣設定」，它很可能把兩代的寫法混在一起交給你。懂 CSS 的人一眼看得出不對；只學過 Tailwind 的新手，就會卡在那裡，而且不知道卡在哪裡。

在 Stack Overflow 上，你一樣會中伏，但中伏之後找得到線索：答案有日期，有人留言說「新版不能這樣寫」。AI 的答案沒有日期，沒有版本標籤，沒有反駁。就算你講明了版本，它也可能悄悄把兩個版本的做法拼在一起。

錯誤沒有變少。變的是，以前的錯是攤開給人看的，現在的錯是包裝好的。

還有一個反諷：AI 本身正是吃 Stack Overflow 那批答案長大的。大家轉用 AI 之後，社群少了人發問、少了人回答。公地不再有人補充，新版本、新框架的問題，就失去了那一層公開驗證。下一代的 AI，也就少了可以學的東西。

最近看到一個例子。一位大學老師在社群上分享，他讓 AI 做了一套可以在自己電腦上運行的 Cloudflare 替代品，一小時完成，並上架到公開的套件庫。他自己寫明：應該算是初版，功能還缺不少。底下第一個留言是：「太棒了。」

一小時做出來的，是介面：程式呼叫起來和 Cloudflare 一模一樣。但這類平台真正難的部分從來不在介面，而在介面背後的承諾：資料出錯時怎樣處理，多個地點之間怎樣保持一致，別人上載的程式怎樣被隔開。這些要經過很多人、很長時間踩過，才知道做對了沒有。

作者那句「初版，還缺不少」，正是 Stack Overflow 年代那種註明適用範圍的好習慣。問題是它被「一小時就做完」蓋過了，而回應它的不是追問，是掌聲。以前的社群會問：你測過哪些情況？現在的回應是按讚。

這也是本文開頭那條界線被跨過的地方。自己用的工具，AI 一小時做完綽綽有餘；但一旦放上公開套件庫，它就可能成為別人專案的地基。寫的成本跌到一小時，驗證的成本沒有跟著跌。公地不只是沒有人補充，而是開始被補上一批沒有人驗證過的東西。

## 摩擦三代：DOS、存檔、Stack Overflow

如果把時間再往前推，會看到同一條規律：摩擦逼人練出深度，摩擦沒有了，深度就不再是預設。

我那一代玩遊戲，先要懂 DOS 指令，否則連遊戲都開不了。想改遊戲，就要用 PC Tools 看十六進位，自然而然學會檔案和記憶體是怎樣運作的。

當年最容易改的，是存檔。以前的遊戲不加密，素材圖、文字稿、存檔都放在資料夾裡，有辦法倒出來、解開來，甚至拿去改。像《三國志英傑傳》，整套改遊戲的玩法幾乎都圍繞存檔：改數值，改招式，改圖。小孩子不懂任何理論，就打開資料夾看看檔案怎樣擺，猜一猜，改一個數字，回到遊戲看看變了甚麼。改錯了，遊戲當機。

這個「猜、改、試、看結果」，就是最原始的科學方法。而且判決者是機器本身，對錯立即知道。和 Stack Overflow 一樣，錯誤是攤開來給你看的。

今天的遊戲大多鎖起來了。這不只是技術進步，背後有一個很清楚的商業原因：一旦遊戲幣可以用真錢買，存檔就變成了錢。你改存檔，等於偷了它的收入。於是存檔搬上伺服器，加密，加反作弊。那個沙盒不是自然消失的，是被商業模式封起來的。

公平地說，模組文化仍然存在，不少遊戲有官方模組工具和創意工坊。但那是官方批准、劃好範圍的遊樂場，和自己挖資料夾、自己猜結構，是兩回事。

深入研究的少數人其實沒有消失，做模組、拆數據、競速的人，鑽得比當年更深。變的是中間那一層。以前普通玩家也被摩擦推著往底層走了半步；現在只剩兩端：極少數很深，大多數完全不碰。這和 Stack Overflow 上寫不寫版本的兩種人，是同一種分化。

遊戲由開放變封閉，知識由公開驗證變黑盒，AI 本身也是一個你看不到裡面的盒子。三件事指向同一個方向：學習者可以自己打開來看的地方，愈來愈少。

## 為甚麼重建不了

要復刻 Stack Overflow，大概沒有可能。那麼 AI 有沒有機會，用以前的模式，讓人公開討論、公開推薦？例如把 AI 的答案變成公開物件，讓人投票、加註、標明「這個在 v4 不對」？

技術上做得到。但有四個死位。

**第一，討論從來不是目的，是代價。** 以前沒有人想討論，只是不問就拿不到答案。問完、答完、被糾正，那份公開紀錄是副產品。AI 一來，代價沒有了，副產品也跟著沒有了。現在直接有答案，還有甚麼好討論？所以單靠「做一個更好的論壇」不會成功，因為沒有人有理由再付那個代價。

**第二，誘因沒有了。** 以前在 Stack Overflow 回答有聲望值，可以寫進履歷，找工作有用。現在替 AI 的答案做驗證，沒名沒利，還是在幫別人改產品。

**第三，平台沒有動機。** 一個公開記錄 AI 錯處的系統，對賣 AI 的公司是負資產。它們寧願你私下按一個「不喜歡」。

**第四，也是最致命的：成本倒轉了。** 以前的網路，洗版和攻擊比較少，管理也比較有資源處理。人手貼一條垃圾，管理員刪一條，成本差不多。今天 AI 生成垃圾近乎零成本，審核卻仍然要人。攻擊方用機器，防守方用人，這場仗怎樣打都輸。Stack Overflow 自己在 2022 年底就已經要禁止 ChatGPT 生成的答案，正是因為量多到管理員處理不來。今天的網路，洗版、廣告和攻擊鋪天蓋地，所有論壇都不容易生存。

更反諷的是，一個專門驗證 AI 答案的論壇，會成為最大的攻擊目標。攻擊它的假投票、假留言，本身就是 AI 造出來的。驗證層會被它想驗證的東西污染，這是一個自我指涉的死結。

這個死結，在寫程式的圈子裡已經出現另一個版本。現在流行的做法，是讓多個 agent 互相 review，人不必再看。有人在討論裡說得很直接：五套 AI 都看不出問題，人也不可能看得出。也有人認為，人給 AI 的技術指導既過時、又滿是自己的盲點，不如不教。

但 Stack Overflow 的驗證之所以有用，在於驗證的人彼此獨立：用不同版本、在不同環境、帶著不同經驗的人，各自試過，再把結果攤開。出自相近訓練材料的幾個 agent，更像同一個人照了幾次鏡子，看到的盲點也一樣。至於「人比較過時」，前面 Tailwind 的例子已經說明，AI 一樣分不清自己身處哪個版本。驗證層沒有因此重建，只是被搬進了另一個看不見裡面的盒子。

討論其實沒有完全死去，而是搬進了 Discord、Slack、公司內部群組。那些地方搜不到、不公開，下一代人找不到，下一代 AI 也學不到。知識由公地變回私家地。

可信的驗證只能退回封閉圈子：邀請制、實名制、收費群組。於是兜了一圈回來：可信的資訊，要付入場費才拿得到。信任由公共品，變成了門票。

## 信任變成商品：萬元 HTML 課賣的是甚麼

到了 AI 時代，割韭菜的歪風捲土重來，這不是巧合。

以前有 Stack Overflow 的時候，想學寫網頁，哪需要花錢上補習班？現在教最基礎的 HTML、CSS，這種完全沒有門檻的東西，居然還敢收上萬元學費。說不定連開課的人，自己的技術都跟不上時代。

但學生還是會買。因為公開的信任層塌了，「信任」本身就成了可以賣的商品。一個萬元 HTML 課，賣的其實不是 HTML，是「有一個人替你背書」。學生付錢買的是確定感，至於導師跟不跟得上，他們根本沒有能力判斷。

這裡有一個很諷刺的位置。萬元課教的 HTML、CSS，偏偏是最穩定、最不需要講版本、官方文件免費寫得清清楚楚的那一部分。十幾年前寫的 CSS，今天照樣能用。版本問題主要出在框架那一層。

而框架那一層，也是最適合收割的：每出一個新版本，課程就可以「更新」一次，再收一次錢。學框架而不懂底層的人，學到的知識會跟著版本折舊。

Tailwind 和純 CSS 我兩樣都會，但我偏好純 CSS，因為我做的東西很多時真的要擺很久。用完即交、多人協作、幾個月後可能推倒重來的東西，用 Tailwind 很合理，快、一致、易協作。但要擺很久的東西，每多一層依賴就多一個會壞的位置：建置工具要升級，框架改語法，文件換網址。純 CSS 不需要建置，瀏覽器看得懂就行，五年後打開照樣能用。

這不是懂不懂的問題，是按壽命選工具。

## 出路：先精通一門學問

這裡要回到我之前寫的〈認知與判斷〉。學習之前，要先想辦法建立你對那門學問的認知和判斷力。否則甚麼課程、甚麼書，都幫不了你。

但這裡有一個雞與蛋的問題：要有判斷力才選得對怎樣學，而判斷力又是學出來的。新手第一天根本沒有判斷力。

以前這個死結由社群替你解。票數、留言、「你用的是哪個版本」，等於社群把判斷力借給你，像一副棚架，讓你一邊學一邊建立自己的，學夠了就不再需要。現在棚架沒有了，新手只能去買。萬元課賣的就是這副棚架，問題是，沒有判斷力的人連棚架是真是假都分不出。

我的答案是：新手的第一副棚架，不必買，可以是自己已經精通的另一門學問。

所有知識和學問的底層原理，應該是相似的。你掌握了一門藝術或學問，真正了解當中的原理，這種認知和判斷就可以搬到其他地方的學習。我由嵌入式系統轉去自學 Java、JavaScript、Python，靠的不是補習班，而是早已知道「學一樣東西，結構是怎樣的」。

回想起來，我自己的路是這樣走的。在澳洲讀書時，中文書很難買，但市中心有一家超大型書店，英文書可以隨便翻、隨便買。學嵌入式系統，ARM、RTOS、C 語言，我會先問教授哪本書好，再去打書釘。教授推薦的，我通常都會買。有一本專業書在澳洲竟然找不到，要經昆士蘭大學的書店，向英國牛津大學書店訂回來。

我偏好 McGraw-Hill、史丹福、MIT 這類大學出版的書，O'Reilly 那類實務書反而很少看。每學一門學問，我至少會有一本專門打基礎的書。大學出版的這類書，通常是一套三本：Fundamentals、Advanced、Expert，另外再有一本大部頭的全集。書實在太貴，我通常只買全集，那一套三本就在圖書館讀完。前提是，你的大學要有一個很好的圖書館。

這一套三本，本身就是一張地圖：先學甚麼，再學甚麼，去到哪裡才算深入。實務書和 AI 給的答案，是食譜；基礎書給的，是骨架。

所以那個「不用花錢」的年代，其實不是免費的。教授、圖書館、大學書店、Stack Overflow，全部都是有人替你付了錢的公地。黃金年代不是因為學習沒有成本，而是成本由公共基建承擔了。教授推薦一本書，通常不會因此抽佣；今天替你推薦課程的人，往往就是賣課的人。推薦者有沒有利益在其中，決定了這一層驗證能不能被信任。

放到今天，可以怎樣起步？到現存不多的書店打書釘，例如天瓏圖書，或者網路書店的試閱。雖然現在的新書也有很多垃圾，但前提是你可以先翻。挑三本你信得過的書，讀完，取得一個基礎的認知和判斷，然後再摸索怎樣學下去。

三本書講法一致的地方，就是那門學問穩定的底；講法不同的地方，就是要你自己判斷的位置。這和在 Stack Overflow 看幾個答案，是同一個原理。打書釘還有一個關鍵：先驗證，後付錢。萬元課剛好相反，先付錢，上完才知道值不值。

不過，精通一門學問不會自動遷移。很多專家在自己的範疇很強，換一個範疇一樣中伏，因為他們會做，但從沒反思過自己是怎樣學會的。要遷移，你必須看得見自己學習的結構。

這正是《遊戲致勝》想做的事。新一代玩遊戲，不必再研究電腦和底層，和我那一代完全不同；會深入研究這些東西的玩家，本來就是少數。所以這本書不假設讀者已經懂底層，而是由上往下給出一個全局觀：產業、設計、經濟怎樣扣在一起。你不必經歷 DOS 年代的摩擦，也可以看見結構。它不是教人打機，而是一個全局觀養成的例子。

## 結語

當年泡在 Stack Overflow 的踏實感，原來不是來自答案，而是來自錯誤。錯誤攤開在那裡，有人指出，有人反駁，你看得見它是怎樣錯的，於是慢慢學會自己分辨。

今天的問題不是人變懶了、不再討論，而是公開討論的環境，已經被成本結構殺死。信任退回圈子裡，成為要付費的門票。

剩下來的選擇只有兩個：一是付錢入圈，二是自己練到懂得驗證。後一條路比較慢，但它練出來的東西不會跟著版本折舊。
