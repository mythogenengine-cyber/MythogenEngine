# 序　結構不需要壞人

## 一、四則消息

假設在2026年10月的某一天，你打開手機，看到四則消息。

一則說，AI 將取代大量白領工作，不學就會被淘汰。一則說，一家老牌餐飲集團和合作了五十多年的夥伴和平分家，各取所需。一則說，年輕人微創業的神話已經破滅，回去上班才安全。還有一則，是一位藝人在節目裡被主持人說，她吃虧，是因為不夠底氣。

四則消息，四個說法：技術進步、好聚好散、創業者太天真、當事人性格有缺陷。每一個說法都有一部分是真的。但它們有一個共同點：都沒有告訴你，錢從哪裡流到了哪裡。

這本書的九章，有四章就是從這四則消息寫起的（見第一、二、七、九章）。

## 二、看懂錢怎樣流

我越來越相信，人生在很大程度上是一場博弈。博弈本身不可怕，可怕的是你不知道桌上有誰、規則由誰定、每一局抽水的又是誰。

而敘事會跟著錢走。收錢的一方，總有理由講一個好聽的故事：轉型、升級、專業化、共贏。付錢的一方，則最常聽到另一種故事：你不夠努力、不夠堅強、跟不上時代。兩種故事未必有人刻意編造，只是錢流到哪裡，哪裡就有人願意把故事講得順一點。

所以這本書只用一個方法。每次聽到一個說法，先不問它對不對，而是問：錢從哪裡流到哪裡？無論你往哪個出口走，站在門口收錢的是誰？

這不是說每一個說法都是假的。AI 是真的有用，正如電腦和互聯網是真的有用。技術是真的，敘事也是真的，兩者同時發生，卻不是同一件事（見[第一章](./ch01.md)）。看懂錢怎樣流，就是把兩者分開來看的方法。

## 三、我站在哪裡

我做過研發，寫過嵌入式系統，在現場替客戶解決問題，後來做企業策略。待過的公司，有在擴張的，有在收購別人的，也有慢慢萎縮的。小時候，我在家族的小商號旁邊長大，看過它擴張，也看過它因為收不回帳而內鬥。這本書裡的很多例子，就是從這些位置看見的。

但我也必須說清楚：我的職涯大半在擴張中的公司度過，真正撞上明槍暗箭，只有一次。第二部會談到，人的位置決定他看見什麼（見[第四章](./ch04.md)）；我自己也是一個位置，一個取樣。

所以你不必全盤相信我看見的。更好的讀法，是拿書裡的問題，去核對你自己看見的。

## 四、這本書不是什麼

它不教你怎樣贏。市面上教人贏的書和課程已經很多，它們大多假設你站在一個公平的舞台上。這本書要談的，恰恰是那個假設不成立的地方。

它不反對科技，也不反對賺錢。別人過得好，未必拿走了你的東西；世界也不是處處零和（見[第四章](./ch04.md)）。

它也不找壞人。這是我最想先說明的一點。書裡寫到的公司、平台、主持、人事部，很少人是存心作惡的。他們每一步，都是對上一步的理性反應；走完一圈，結果卻落在一個沒有做錯什麼的人身上。結構不需要壞人。正因為不需要壞人，它才這麼難看見，也才這麼容易被講成你自己的問題。

## 五、怎樣讀這本書

全書分三部，各問一個問題。

第一部（第一至三章）問：這個結構是什麼形狀？從一家公司內部被置換的研發部門，到餐桌上變了味的雞，到每一條出路的入場費。

第二部（第四至六章）問：為什麼你看得見，別人看不見？反過來也一樣：為什麼你看不見，別人看得見？

第三部（第七至九章）問：結構的代價落到一個人頭上之後，是怎樣被講成那個人的缺陷的？

終章嘗試回答：知道了這些之後，可以做什麼。

書裡的例子，幾乎都寫上了日期，大多是2026年。這是刻意的。十年後，書裡的公司可能已經上市或者賣掉，店可能已經關了，平台可能已經改了名字，AI 也許已經換上下一輪的名字。到那時候，這些例子會變成一份記錄：一個人在2026年看見的世界。

要帶走的不是例子，而是方法。很多章節的結尾都留下幾個問題，不需要內部資料也問得出口，也不會因為換了一個平台、換了一個技術名詞就失效。你不認識書裡的人物、沒聽過那些風波，也不要緊。例子是記錄，方法是工具。記錄會老，工具不會。

每一章都可以單獨讀；章與章之間以「（見第X章）」互相指引。引用的資料和我其他的文章，以註釋編號；網頁版的註釋附於各章末。

書名來自第九章的一個問題：無論往哪個出口走，站在門口收錢的是誰？副題是終章的答案。中間九章，是從問題走到答案的路。
