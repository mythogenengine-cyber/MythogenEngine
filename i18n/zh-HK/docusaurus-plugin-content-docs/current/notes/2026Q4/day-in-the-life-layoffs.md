# 一條上班日常影片如何變成裁員理由：沒有資本的人在懲罰沒有資本的人

從乞丐碗裡搶飯系列 · @Mythogen Engine · Nov 21, 2026

## 一、乞丐只妒忌乞丐

羅素在1930年出版的《幸福之路》（The Conquest of Happiness）裡，用了一整章談嫉妒。其中一句是：「乞丐不會妒忌百萬富翁，但當然會妒忌比自己更成功的乞丐。」他的解釋是，人不會妒忌一份自知遙不可及的好運。嫉妒需要距離夠近，近到讓人覺得那本來可以是自己。

將近一百年後，這句話在微軟身上又應驗了一次。2026年10月26日，微軟宣布「自願離職方案」（Voluntary Exit Offer），向美國、加拿大、印度和英國約六萬名符合資格的員工提出買斷，約佔全球二十二萬三千名全職員工的27%。同一個月，微軟股價創下歷史新高。

消息傳出後，一條2025年的舊影片被翻了出來。一名在微軟印度海得拉巴辦公室工作的24歲工程師，拍下自己上班的一天：早餐、甜品、零食、打機。影片配上「難怪微軟要裁六萬人」之類的標題再次瘋傳，討伐聲蓋過了一切。

被罵的是一名入職不久的年輕工程師。很少人追問，一間股價創新高、大舉投資AI的公司，為甚麼要讓四分之一員工「自願」離開。乞丐們的目光，再一次落在隔壁那隻碗上。

## 二、影片拍了甚麼，沒拍甚麼

影片的主角叫 Mansi Singhal。她在片中自己說，通常早上九點到辦公室，傍晚六點半離開。各家報道的描述大致一致：畫面裡有45分鐘的早餐、甜品、打機和幾次拿零食。影片爆紅之後，她發文承認自己傾向展示開發者生活「好的一面」，現實往往更混亂、更辛苦。

到了一些中文頻道口中，故事變成了另一個版本：九點先去健身室、洗澡，十點半才開工，下午四點二十分收工。四點二十分這個時間，我在主流報道中找不到。就算用這些頻道自己的算法，她一天坐在工位上的時間也有六小時。如果以她本人的說法計算，她在辦公室的時間是九個半小時。

更重要的是鏡頭以外的東西。寫程式的畫面沒有人想看，公司資料也不能拍。旺季趕交付、半夜 on-call、跟大洋彼岸總部開的時差會議，都不會出現在一條十幾秒的 reel 裡。「上班日常」這種片型本來就是為好的一面而生的，因為只有好的一面才有人看。

任何做過項目的人都知道，工作有旺淡季。旺季一天十幾個小時，淡季放鬆一點，只是求一個平衡。可是觀眾的尺子只量得到一樣東西：看不看得到辛苦。產出是看不見的，辛苦是看得見的，於是看得見的辛苦就被當成了價值。

## 三、福利是留人的設計

微軟海得拉巴的研發中心佔地五十四英畝。報道提到的設施包括全天候多菜系食堂、健身室、午睡房、藥房、全天候救護車，還有附 Wi-Fi 的冷氣交通車。

這些不是送給員工的禮物，而是一套設計。食堂二十四小時開，晚飯就可以在公司吃。交通車有 Wi-Fi，通勤時間就可以變成工作時間。有午睡房，就不必回家睡。每一項設施都在減少一個離開辦公室的理由。

所以問題不應該是「她有多悠閒」，而是反過來問：健身之後，她要加班到幾點？有沒有早到的日子沒拍進去？一間公司叫你「把這裡當成家」，是不是就想你把所有時間都留在這裡？

更諷刺的是，這類影片本來就是招聘廣告。2024年有一條海得拉巴員工展示福利的影片，微軟的官方帳號 Microsoft Life 還留言叫好。同一種影片，擴張期是僱主品牌，縮編期就變成裁員的證據。觀眾看到的是誘餌，却以為看到了偷懶。

## 四、勤到沒時間睡的人

如果問題真的是勤力，那麼勤力的人應該得到不同的判決。2026年11月，YouTube 頻道「胡萝卜」發布了一條片，記錄橫店一名短劇演員的生活。宋年歡今年26歲，2023年11月到橫店，當時只要想拍就有戲拍。今年AI短劇興起，許多短劇公司倒閉，她5、6月合共只拍了一天戲，7月拍了兩天。

為了生活費，她擺攤賣手打檸檬茶。傍晚五六點開始準備冰塊，收攤要到凌晨一點半至兩點，遲的時候到三點半。生意最好的一晚收入約280元，夏天差的時候一百多元。最焦慮的那段日子，她經常哭，試過整整二十四小時睡不著。

這是一個勤到沒多少時間睡的人。留言區對她的判決卻沒有改變多少：有人說她「確實不夠優秀」，否則應該去當AI工程師；有人說「選擇大於努力」；有人問她「自身真的努力了嗎？」；也有人乾脆說她本來就是擺地攤的料。最讓人難受的是，她在片頭就已經對自己下了同一個判決：「是我不夠努力，我不夠優秀。」

把兩條片放在一起，判決的結構就很清楚：

- **不夠勤**：判你該被炒。
- **勤到沒覺睡仍然輸**：判你選錯行、不夠優秀。
- **拍好的一面說你偷懶，拍辛苦的一面說你賣慘**：這條片的留言區，就真的有人認為她「高機率演的」。

判決一早就定了，理由只是跟著換。「勤力」不是量度的標準，而是用來判人的說詞。這套信念最厲害的地方，是連被判的人自己也相信。

這條片沒有主持人帶風向，留言區也不全是判詞。最多讚的一句是「時代的一粒沙，落在普通人身上就是山崩地裂」（140個讚）；也有人反駁「選擇大於努力」，指出在這句話之前，大多數人只是運氣好。

## 五、賣門票的人

把這場嫉妒組織起來的，不是乞丐，而是賣門票的人。香港頻道「屈機TV」有六十一萬訂閱者，2026年11月12日推出《屈機觀察》EP441，標題是「微軟清洗印度裔職場蛇王，白宮用完即棄封殺綠卡申請！」到本文撰寫時，影片約有30萬次觀看、7,501個讚。

主持人葉文斌在片頭沒多久，其實說了兩件對的事。第一，微軟已經澄清，這是員工自行選擇的買斷計劃，不是針對單一族裔的解僱。第二，公眾的怒氣沒有指向決策層。然後，他用接下來的十九分鐘，把怒氣引向印度裔員工，把整個計劃說成對印度裔熟人網絡的「戰略清算」。

片中的關鍵說法，可以逐條對照公開紀錄：

| 影片說法 | 公開紀錄 |
| --- | --- |
| 「微軟六萬人大裁員」 | 六萬是符合資格申請的人數，不是裁員數；員工自行選擇，12月初前決定 |
| 女工程師十點半開工、四點二十分收工 | 她本人說九點到、六點半走；主流報道未見四點二十分 |
| 萬斯指微軟裁了6,000名美國員工，另申請超過2,200個H-1B | 萬斯原話是裁6,000人、受惠於6,300個H-1B和近3,000張綠卡；CNBC 分析指微軟三分之二的H-1B批核屬現有員工；微軟稱持H-1B的員工同樣被裁 |
| 勞工部暫停微軟等公司申請綠卡 | 屬實：10月8日暫停微軟、Adobe及六間IT公司的PERM勞工認證，不影響現有H-1B |
| 印度出生者佔H-1B七成以上，中國11.7% | 屬實（2024財年）；但這是簽證持有人的出生地，不是高管的族裔 |
| Cognizant 案證明印度裔排外 | 判決屬實：2024年10月陪審團裁定該公司歧視非印度裔員工，公司表示上訴；但它是外判公司，不是微軟；片中「8.3%」未找到出處 |
| 矽谷副總裁以上印度裔佔32%，華裔只有4% | 未找到出處；BBC 2021年報道指印度裔約佔美國人口1%、矽谷勞動力6% |

片中的誤導主要靠三種手法：

1. **偷換數字**：「六萬人符合資格」被講成「六萬人大裁員」。一個員工自行選擇的方案，變成了一場強制清洗。
2. **真假混搭**：H-1B比例、PERM暫停、Cognizant判決都是真的，它們負責搭架子；查不到出處的32%對4%，則放在結論的位置。聽眾驗證了前半部，就把後半部一併接受。
3. **自己推翻自己**：片頭承認微軟已經澄清不是針對任何族裔，接著用整條片把計劃說成針對印度裔的「戰略清算」。前面那句澄清讓節目看起來持平，後面十九分鐘才是觀眾帶走的東西。

門票是怎樣賣的也很清楚。片中插了一段中藥廣告，頻道商店賣杯、書和感冒藥，說明欄還有 WhatsApp 廣播群組。怒氣就是流量，流量就是廣告位。主持人不是乞丐，他是在廣場邊賣票、請人看乞丐打架的人。

留言區是成果。在「最熱門」排序下，獲得最多讚的留言已經離開了微軟：有人質問香港政府為甚麼還在批印度專才（103個讚）；有人說「從此辦公室便失去了一份熟悉的咖哩味」（46個讚）；有人把一對印度父女在香港派飯盒、南亞裔義工增加，解讀成「攻心計劃」（55個讚）。有觀眾笑說微軟當天死機是印度工程師「發力」，主持人葉文斌本人的帳號（@terry.ymp1101）在留言區逐一向支持者道謝，對這句則回覆「有可能😂」。

不是所有人都買票。有人寫「一人得道，雞犬升天。呢樣係無分種族。」（1個讚）；有人指本地人一樣飲咖啡吹水，說到底只是大公司割羊毛（2個讚）；有人問「你資料邊到嚟？」（0個讚）。懷疑的聲音一直都在，只是沒有人給它讚。

拿上一節那條橫店影片來比較，分別很明顯：那裡最多讚的留言談時代，這裡最多讚的留言談族群。兩條片只是兩個樣本，說明不了全部，但至少可以看到：有人賣門票的時候，觀眾的判斷會一面倒得多。

魯迅在1919年的〈隨感錄六十五〉裡，早就寫過這種心態：

> 暴君治下的臣民，大抵比暴君更暴；暴君的暴政，時常還不能饜足暴君治下的臣民的慾望。……暴君的臣民，只願暴政暴在他人的頭上，他卻看著高興，拿「殘酷」做娛樂，拿「他人的苦」做賞玩，做慰安。自己的本領只是「幸免」。
>
> 從「幸免」裡又選出犧牲，供給暴君治下的臣民的渴血的慾望，但誰也不明白。死的說「阿呀」，活的高興著。

留言區裡喊「做得好」的人，慶祝的是自己暫時幸免。他們沒有想到，下一次從「幸免」裡選出的犧牲，可能就是自己。

## 六、換成族群的故事

一旦變成族群問題，結構就從畫面裡消失了。這場討論裡至少有三個版本：印度人靠表演和裙帶上位；華人勤奮內斂、不屑包裝，所以升不上去；以及在留言和私下談話中常聽到的，華人升不上去是因為被當成間諜。三個版本的共同點，是把一個制度問題說成民族性格問題。

差距是真的。Jackson Lu、Richard Nisbett 和 Michael Morris 2020年在《美國國家科學院院刊》（PNAS）發表的研究，綜合九項研究、一萬一千零三十人的樣本，發現東亞裔比南亞裔和白人更難升上領導層，南亞裔甚至勝過白人。2017年標普五百大企業的16名亞裔CEO中，13名是南亞裔，只有3名是東亞裔。

但研究找到的原因，不是裙帶，也不是品德。差距一直用「主動表達」（assertiveness）的文化差異解釋得到，偏見和動機都解釋不了。東亞文化裡的不出聲是穩重，在美國的領導文化裡就變成沒有自信。作者的結論是，這是文化適配的問題。「華人太乾淨」的說法把這個不適配包裝成美德，聽眾聽得舒服，却什麼也學不到。

間諜論也解釋不了數據。美國對中國籍人員的安全疑慮確實存在，但研究裡的「東亞裔」包括韓國人和日本人，他們一樣升不上去。研究也發現，美國出生的東亞裔同樣有這個差距。土生土長的美國人，不會因為間諜疑慮而升不了職。

這不等於說同鄉偏庇不存在。Cognizant 案就是在法庭裡證實的例子：2024年10月，聯邦陪審團裁定這間外判公司在2013至2022年間故意歧視超過二千名非印度裔員工。但這是一間公司、一個制度、一份證據的問題，要一家一家地查，不能推成一個民族的天性。

華人社會也不缺這套。同鄉會、宗族生意、校友圈、飯局拉關係，在香港和台灣都是日常。開一個大 call 叫齊一群人顯示自己重要、搶著向上報告、排隊企位，我在華人公司裡都見過。哪裡的產出難以量度、評分靠上司觀感、層級多到上面看不到下面，哪裡就會有人做騷。留言區那句只拿到一個讚的話，其實說得最準：一人得道，雞犬升天，無分種族。

## 七、裁員醫不好大公司病

屈機把這次買斷說成「清理蛇王」、醫治大公司病。這個說法有三個問題。

第一，自願離職趕走的，往往是有得選的人。能力強、在外面找得到工作的人，最容易拿著賠償走；走不動的人反而留下。微軟2026年4月曾向約8,750名美國資深員工提出自願退休，約三成接受。誰接受、誰拒絕，是個人的計算，不是公司的篩選。

第二，官僚是跟著結構來的，不是跟著人數來的。審批有幾層、報告要交幾份、KPI 怎樣定，這些都不會因為走了人而改變。人少了、流程不變，就是更少的人做同樣多的匯報。每個人都怕自己是下一個，做騷只會更多。

第三，創新需要空檔。淡季的鬆動就是空檔，有空檔才有人試新東西、做一些未必有回報的嘗試。把所有空檔當成浪費剔走，剩下的就只是維持現狀。

要公道地說，這次買斷本來就不是為了醫大公司病。各家報道的說法一致：微軟是在大舉投資AI的同時壓縮成本。用這把尺來量，它未必失敗。裁員解決的是財務報表上的問題，不是組織的問題。公司對外喜歡把前者包裝成後者，而屈機這類頻道替它補上了最後一塊：一個道德故事，讓裁員看起來是「應得的」。

## 八、同一個前提，換了場景

這個系列的第一篇寫屯門富泰邨的女童搬啤酒事件。當時幾個頻道把一個家庭變成綜援濫用的證據，背後的前提是「不做就該受苦」。這一篇的前提完全一樣，只是換成了白領版本：不夠苦，就該被炒。

一個在屋邨、一個在微軟，場景隨時可以換，結構從來不變。決定誰去誰留的人在鏡頭外，鏡頭裡只有一群沒有資本的人，互相檢查對方夠不夠辛苦。懲罰不勤力的人，實際上是沒有資本的人在懲罰沒有資本的人。

而且這把尺不會停在別人身上。社會一旦接受「看不到辛苦就不配得到資源」，這個標準就會從底層一路往上傳，由綜援家庭到外勞、到專才、到白領，最後量到今天在留言區拍手的人身上。

羅素說明了嫉妒為甚麼只射向身邊的乞丐，魯迅說明了他人的苦為甚麼會變成旁觀者的娛樂。中間只差一個角色：把這兩種心態接起來、在廣場邊賣票的人。下次再看到「難怪要裁員」這種標題，或許可以先問一句：真正應該被問的人，為甚麼一直不在畫面裡？
